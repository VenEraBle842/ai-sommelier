# Локальный каталог «Своё Вино»

Текущий этап MVP: реальный HTML-каталог → детерминированный парсер → SQLite.
Рекомендации, пользовательская история и LLM пока не реализованы.

Нужны Python 3.14 и [uv](https://docs.astral.sh/uv/). Зависимости зафиксированы
в `uv.lock`. Выполняйте команды из корня проекта:

```bash
uv sync --locked
uv run python -m app.catalog.sync --pages 2 --limit 30
```

База `data/catalog.sqlite3` и её папка создаются автоматически. В рабочей базе
нет искусственных вин: её наполняет только отдельная синхронизация с
https://vino-svoe.ru/wines. Для синхронизации нужен доступ в интернет.
Повторный запуск обновляет поля и дату загрузки, сохраняя локальный `id`.

```bash
uv run python -m app.catalog.sync --help
uv run python -m app.catalog.sync --pages 1 --limit 3 --db data/проверка.sqlite3
uv run uvicorn app.api.main:app --log-level warning
```

API: `GET /wines?limit=50&offset=0` и `GET /wines/{wine_id}` на
http://127.0.0.1:8000. API читает только локальную базу и не обращается к сайту.
`WINE_DB_PATH` задаёт другой путь базы для API и синхронизации; `--db` имеет
приоритет для команды. Схема API доступна по `/openapi.json`.

Проверки выполняются без сети:

```bash
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run mypy
```

В `tests/fixtures/README.md` указано происхождение сохранённых фрагментов HTML.
Тесты проверяют поля реальных карточек, отсутствие выдуманных данных,
повторную синхронизацию, ограничения обхода, сетевые сбои и чтение API.

## Границы текущего этапа

- Цена не подтверждена: `price_rub` всегда `None` без отдельного доверенного
  `PriceProvider`. Парсер игнорирует любые ценоподобные числа. Фильтрация по
  бюджету пока недоступна. Тестовый поставщик цен используется только в тесте.
- Крепость и температура сохраняются строками: исходные диапазоны не усредняются.
  Цвет и сладость нормализуются по известным значениям; исходная категория и
  оттенок сохраняются отдельно. Неизвестное значение не угадывается.
- Рейтинг берётся только из явно подписанного народного рейтинга карточки,
  в диапазоне 0–5. Пустые поля остаются `None` или пустыми списками.
- Загрузчик последовательный: тайм-аут 20 секунд, пауза не меньше секунды,
  два повтора временных сетевых ошибок с увеличением задержки. Учитываются
  robots.txt и `Crawl-delay`. HTTP 401/403/429, CAPTCHA, перенаправление и
  `Retry-After` прекращают запуск; обхода ограничений нет.
- `--pages` ограничивает страницы (по умолчанию 1000), `--limit` — попытки
  загрузки уникальных карточек, включая неудачные. Ошибка отдельной карточки
  не мешает другим; итоговый код при ошибках — 1. Прерывание — 130.
  Уже сохранённые карточки остаются в базе.
- Синхронизация перечитывает выбранные карточки и обновляет их через upsert;
  условные HTTP-запросы пока не используются. Удалённые с сайта записи
  автоматически не удаляются. Миграции схемы пока не реализованы.
- Парсер зависит от текущих CSS-классов сайта. Ошибка структуры каталога
  останавливает обход, неполная карточка без названия не сохраняется.
  Доступность сайта проверяется отдельно от автономных тестов.

В проекте нет локальных моделей, эмбеддингов, векторной базы и облачного
развёртывания. Git-коммиты и отправку в удалённый репозиторий выполняет разработчик.
