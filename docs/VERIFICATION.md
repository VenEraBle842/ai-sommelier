## Чистая установка

Python 3.14.8. Выполнена установка по неизменённому `uv.lock`:

```bash
UV_PROJECT_ENVIRONMENT=/tmp/svoevino-final-clean-venv uv --cache-dir /tmp/svoevino-uv-cache sync --locked
```

Первый запуск с `--offline` остановился из-за отсутствующих пакетов в кэше.
После разрешённой загрузки из PyPI установка успешно завершилась: 36 пакетов.
Окружение находится в `/tmp/svoevino-final-clean-venv`, кэш загрузок —
в `/tmp/svoevino-uv-cache`; рабочая `.venv` не заменялась. Клонирование GitHub
повторно не выполнялось: адрес в README сверён с существующим Git remote.

Из этого окружения выполнено:

```bash
UV_PROJECT_ENVIRONMENT=/tmp/svoevino-final-clean-venv uv --cache-dir /tmp/svoevino-uv-cache run python -m app.demo --offline --db /tmp/svoevino-clean-demo.sqlite3 --port 8765
```

SQLite и таблицы создались автоматически; импортированы три реальные карточки.
Приложение открылось в браузере. Внешние API не вызывались; для открытия
локального порта потребовалось разрешение вне файловой песочницы.

## Проверка интерфейса в браузере

Проверен настоящий FastAPI-сервер, без подмены HTTP-ответов или изменений DOM.

- Видны русские подписи, примеры, вопрос и объяснения.
- Проверены один уточняющий вопрос, сохранение предыдущих условий и выдача
  трёх реальных карточек.
- Лайк сохраняется и меняет порядок следующей подборки; объяснение явно
  связывает результат с пользовательской оценкой.
- Подробная карточка показывает факты, исходный URL и «Не указана» для цены.
- Проверены широкий экран 1440×1000, исходное окно около 1000 пикселей и узкий
  экран 390×844. По DOM ширина документа не превышала ширину окна; карточка
  в диалоге также не имела горизонтального переполнения. Временный размер
  браузера после проверки сброшен.
- «Розовое сухое» даёт понятное отсутствие кандидатов; ограничения не ослабляются.
- При недоступности проверочного сервера показано русское сообщение о связи,
  сохранённый текст и кнопка повтора, без JSON или трассировки. После запуска
  сервера повтор успешно отработал. Наблюдалось и русское состояние загрузки.
- Новый дизайн или декоративные элементы не добавлялись: выявленных проблем
  вёрстки, требующих изменения текущего оформления, не обнаружено.
